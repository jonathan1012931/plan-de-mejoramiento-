Mobile First Architecture

Guía de Estilos & Componentes UI

Bienvenido al sistema de diseño interactivo de Sport Zone. Diseñado desde cero bajo la filosofía Mobile First, este documento interactivo expone los componentes principales en sus 5 estados clave (Default, Hover, Active, Focus, Disabled).

Evaluación completa de comportamiento interactivo en controles de acción.

2. Hover

3. Active

Respuesta visual al hacer clic (presionado).

4. Focus

Enfoque de accesibilidad por teclado.

Bloqueado para interacción del usuario.
